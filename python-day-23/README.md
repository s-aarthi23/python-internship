Day 23 – Python "os" Module

📌 Topics Covered

Today, I learned about the Python "os" module and how it can be used to work with files, folders, and paths.

🔹 Concepts Learned

- "os.getcwd()" – Get the current working directory
- "os.listdir()" – List files and folders
- "os.mkdir()" – Create a new folder
- "os.path.exists()" – Check whether a file or folder exists
- "os.makedirs()" – Create nested directories
- "os.rmdir()" – Remove an empty folder
- "os.rename()" – Rename a file or folder
- "os.path.join()" – Join folder and file paths
- "os.path.isfile()" – Check whether a path is a file
- "os.path.isdir()" – Check whether a path is a directory

💻 Practice

I practiced creating, checking, renaming, and removing folders using the "os" module.

I also practiced working with file and folder paths using "os.path".

🧠 Key Learning

The "os" module helps Python interact with the operating system and makes file and directory management easier.
