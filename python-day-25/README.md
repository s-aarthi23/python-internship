# Day 25 – shutil Module 🐍

Today I learned about the `shutil` module in Python.

## What I Learned

- `shutil.copy()` – Copies a file.
- `shutil.copy2()` – Copies a file while preserving metadata.
- `shutil.move()` – Moves or renames files and folders.
- `shutil.rmtree()` – Deletes a folder and its contents.

## Practice

I practiced:
- Copying a Python file
- Creating a backup using `copy2()`
- Moving/renaming a file
- Moving a folder
- Deleting a folder using `rmtree()`

## Key Learning

The `shutil` module is useful for managing files and folders programmatically in Python.
