Day 24 – Python os.path

📚 Topics Covered

- "os.getcwd()" – Get the current working directory
- "os.path.exists()" – Check whether a path exists
- "os.path.isfile()" – Check whether a path is a file
- "os.path.isdir()" – Check whether a path is a directory
- "os.path.join()" – Join path components
- "os.path.basename()" – Get the file name from a path
- "os.path.dirname()" – Get the directory name from a path
- "os.path.splitext()" – Split file name and extension
- "os.path.getsize()" – Get file size
- "os.path.abspath()" – Get the absolute path
- "os.path.getctime()" – Get creation/change timestamp
- "os.path.getmtime()" – Get last modified timestamp
- "os.path.samefile()" – Check whether two paths refer to the same file

💻 Practice

Created a small Python program using "os.path" functions to work with files and directories.

The program displays:

- Current working directory
- File name
- Folder path
- File extension
- File existence
- File size
- Absolute path

Learned how to work with file and directory paths in Python using the "os.path" module.
