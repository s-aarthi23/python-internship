# 🐍 Day 30 – Student Management System

## 📌 Overview
Created a simple Student Management System using Python by combining the concepts learned in the previous days.

## 📚 Concepts Used
- Lists
- Dictionaries
- For Loop
- If, Elif, Else
- User Input
- String Methods
- Pass/Fail Checking
- Grade Calculation
- Searching

## 🛠️ Features
- Add multiple student details
- Store student information using dictionaries
- Calculate Pass/Fail result
- Calculate student grade
- Display all student details
- Search for a student by name

## 🎯 Learning Outcome
Learned how to combine basic Python concepts to build a simple real-world mini project.
