# Day 34 – Stack

## Topic
Stack Data Structure

## What I Learned

- Stack follows LIFO (Last In, First Out).
- Push operation is used to add an element.
- Pop operation is used to remove the top element.
- Peek/Top is used to view the top element.
- `not stack` is used to check whether the stack is empty.

## Key Point

LIFO – Last In, First Out

The last element added to the stack is removed first.

- Pop operation
- Peek/Top operation
- Empty stack checking
