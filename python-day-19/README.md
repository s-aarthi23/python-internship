Day 19 – JSON

📌 What I Learned

Today I learned about JSON (JavaScript Object Notation), a lightweight data format used to store and exchange data between applications. I learned how to convert Python objects to JSON and JSON back to Python objects using the json module.

📚 Topics Covered

Introduction to JSON

Importing the json module

json.dumps() – Python object to JSON string

json.loads() – JSON string to Python object

json.dump() – Write Python object to a JSON file

json.load() – Read JSON data from a file

Dictionary ↔ JSON conversion


💻 Practice Programs

1. Converted a Python dictionary to a JSON string using json.dumps().


2. Converted a JSON string to a Python dictionary using json.loads().


3. Stored dictionary data in a JSON file using json.dump() and read it back using json.load().



🎯 Outcome

Successfully understood how to work with JSON data in Python, convert data between Python objects and JSON format, and read/write JSON files for data storage and exchange.
