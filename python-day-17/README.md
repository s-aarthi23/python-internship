## 📝 What I Learned
Encapsulation is the process of wrapping data and methods together inside a class and controlling direct access to the data.

### Access Types:
- **Public** – Can be accessed directly.
- **Protected (`_`)** – Intended for use within the class and subclasses.
- **Private (`__`)** – Used to restrict direct access to data.

### Getter
Used to read or access private data.

### Setter
Used to update or modify private data.
