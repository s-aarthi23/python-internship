# Day 12 – Exception Handling 🐍

## 📌 Topics Covered

Today I learned about **Exception Handling in Python**.

### 1. try
Used to write code that may cause an error.

### 2. except
Used to handle errors without stopping the program.

### 3. else
Runs when there is no error in the `try` block.

### 4. finally
Runs whether an error occurs or not.

### 5. raise
Used to manually raise an exception.
